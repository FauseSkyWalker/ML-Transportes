# ML-Transportes

Este repositório foi desenvolvido no contexto de um projeto de PIBIC, referente ao processo de iniciação científica do aluno Fause Caros Mascarenhas Lustosa Junior, Engenheiro de Software pela UnB. O principal objetivo do trabalho é realizar análises com machine learning e exploração de dados a partir da base de dados aberta da PRF, relacionada a acidentes de trânsito em todo o território nacional.

## Objetivo

Este repositório tem como finalidade organizar os materiais relacionados ao projeto ML-Transportes, incluindo experimentos, análises, treinamentos e versões mais consolidadas para uso em trabalhos futuros.

## Estrutura do repositório

- `pibic/`: área de rascunho, testes, protótipos e materiais em desenvolvimento.
- `final/`: pasta com os códigos mais importantes, versões consolidadas e arquivos com maior relevância para uso em trabalhos futuros.

## Como navegar pelo repositório

- Para acessar materiais em fase inicial e experimental, consulte a pasta `pibic/`.
- Para encontrar os códigos principais e mais relevantes, utilize a pasta `final/`.
- Em geral, a pasta `final/` deve ser o ponto de partida para reutilização, validação ou continuidade do trabalho.

## Recomendações de organização

- Arquivos experimentais, testes e versões preliminares devem permanecer em `pibic/`.
- Quando um arquivo estiver mais consolidado e demonstrar valor para uso futuro, ele deve ser movido ou copiado para `final/`.
- Este README pode ser atualizado conforme novas pastas, scripts ou notebooks forem adicionados ao projeto.

## Próximos passos

- Revisar os arquivos da pasta `final/` para identificar os componentes mais relevantes.
- Documentar individualmente os scripts, notebooks e modelos conforme necessário.
- Manter a pasta `pibic/` como espaço de rascunho e evolução do projeto.
